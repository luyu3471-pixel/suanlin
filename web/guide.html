系统说明

多终端任务调度系统是办公巡检事件文本任务的多终端协同原型，采用 Python 标准库实现，可在离线环境运行。

快速开始

python launch.py

浏览器访问 http://127.0.0.1:8765。默认会启动两个同机执行进程。创建任务后，系统将文本分配给节点执行真实分类推理。

远程执行端

python launch.py --host 0.0.0.0

python -m suanlin.worker --coordinator http://协调端IP:8765 --token-file token.txt --name 办公室节点B

将协调端 .local/access_token 的内容安全保存到执行端 token.txt。远程节点默认未设为可信，需在协调端核实后设置。仅在隔离或可信局域网内使用 HTTP；跨网络部署需要另行配置 TLS 与访问控制。

源文件与完整资料

README.md 提供完整操作。docs 提供场景设计方案、视频讲稿、答辩问答、两人分工与多机测试方案。results 保存仿真与本机验证数据。delivery 保存参赛用 PDF、演示文件与压缩包。

数据口径

应用层时延由协调端记录。带宽是配置值，HTTP 往返耗时包含软件开销。内置模型使用 48 条合成样本训练，尚未验证真实巡检效果。仿真结论与物理设备测量分别呈现。
