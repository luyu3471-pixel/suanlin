# 界面精简与动态呈现

更新日期：2026-11-12。

## 调整范围

本轮沿用现有界面和技术栈。原动态横幅的扫描、粒子、节点图与连线动画保留；新手引导仍是额外入口。侧栏此前移除的两个组件不恢复。

| 页面 | 默认呈现 | 详细内容入口 |
|---|---|---|
| 工作台 | 原动态横幅、统一底色的指标、全宽动态拓扑、并排节点任务面板；调度说明改为三段流程图 | 调度机制、进度与动效口径、环境与指标口径 |
| 节点 | 状态与连接、CPU/内存/执行槽的负载条、暂停与可信操作 | 设备配置与测量口径 |
| 对比实验 | 本机与远端的比例耗时图，分出计算、通信、排队；带宽滑块可实时改变选择 | 计算与回传参数、推演边界、完整仿真指标 |
| 部署与验证 | 协调端和执行端关系示意、三个可点击步骤、当前步骤说明与命令 | AI、通信与安全、材料复现、AI与6G关联 |

任务创建、结果查看、CSV导出、节点控制、原演示按钮和已有实验继续通过原接口工作。默认页面去掉重复英文小标题；长说明按需展开，保留必要的事实与验证边界。

## 动效与数据口径

- 原横幅动效保留。
- 拓扑新增沿连线移动的短标记，仅在实际运行任务或近期结果接收状态出现；离开视口时暂停。它是任务状态示意，不是抓包或流量测量。
- CPU、内存和槽位条按上报数据平滑变化；未知值不填成零，过期上报明确标记。
- 耗时图在调整参数时平滑改变长度。带宽滑块采用对数刻度，覆盖 0.1 至 10000 Mbps，数值输入仍可直接填写。推演只在浏览器中计算，不提交任务、不修改节点带宽。
- 部署图在点击步骤时演示连接关系，明确标为示意，不用它冒充实际连接状态。
- 继续遵循页面动效开关、系统减少动态效果设置和后台暂停。
