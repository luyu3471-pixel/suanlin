# 多终端任务调度系统两人分工与交付计划

## 工作边界

成员A负责软件工程，成员B负责电子信息与实验。两人共同审核业务真实性与所有对外结论。每天约1小时，优先补真实证据；硬件预算有余也先使用已有电脑，不为展示增加无必要设备。

## 采购原则

第一阶段只需两台能运行Python的电脑和可信网络。若已有设备可用，新增硬件采购为零。网络问题影响验证后再考虑借用有线连接或交换设备；重模型需要算力时再确认型号和许可证。当前不需要无人机、开发板或专用6G仪器。

## 每日复核

每天结束保存一个具体成果，并写明由谁生成、由谁复核、存放位置与未解决问题。发生结果不一致时保留原始记录后再定位问题，不覆盖失败实验。最后一周优先理解系统与练习回答限制问题，减少扩大功能范围。
